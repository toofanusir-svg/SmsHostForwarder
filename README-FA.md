# ارسال‌کننده پیامک (SMS Forwarder)

برنامه‌ای برای اندروید که پیامک‌ها و اطلاعات تماس‌های ورودی را به ربات تلگرام و/یا وب‌هوک سفارشی شما ارسال می‌کند — با امکان فیلتر بر اساس سیم‌کارت و شماره فرستنده.

> **نکته:** این پروژه یک fork از [vovaksenov99/SmsHostForwarder](https://github.com/vovaksenov99/SmsHostForwarder) است.
> برنامه اصلی فقط ارسال به تلگرام را پشتیبانی می‌کرد. در این fork امکانات زیر اضافه شده:
> قوانین چندگانه، ارسال به وب‌هوک، تایید OTP، رمزنگاری AES-256، لاگ ارسال، تست هر قانون، تنظیمات زبان/تم، و برنامه رمزگشا.

## امکانات

- **ارسال بر اساس قانون** — چندین قانون با فیلتر سیم‌کارت، شماره فرستنده و مقصد جداگانه
- **مقصد دوگانه** — هر قانون می‌تواند هم‌زمان به تلگرام و وب‌هوک ارسال کند
- **فیلتر سیم‌کارت** — ارسال از سیم‌کارت اول، دوم یا هر کدام
- **فیلتر فرستنده** — ارسال از شماره خاص یا همه فرستنده‌ها
- **لاگ ارسال** — مشاهده دقیق اینکه چه ارسال شده، چه زمانی و آیا موفق ✅ یا ناموفق ❌ بوده
- **تلاش مجدد** — دکمه Retry برای ارسال‌های ناموفق
- **تست هر قانون** — قبل از ذخیره، مقصد قانون را تست کنید
- **تست کلی** — همه قوانین را هم‌زمان از صفحه اصلی تست کنید
- **فعال/غیرفعال کردن قانون** — بدون حذف، قانون را موقتاً غیرفعال کنید
- **زبان فارسی و انگلیسی**
- **تم روشن و تاریک**
- **سرویس پس‌زمینه** — همیشه فعال، بعد از ریست دستگاه خودکار روشن می‌شود
- **پشتیبانی اندروید ۸ به بالا**

## برنامه رمزگشا

**SMS Decoder** یک برنامه همراه است که در همین پروژه قرار دارد. پیام‌های رمزنگاری‌شده‌ای که توسط ارسال‌کننده پیامک به وب‌هوک فرستاده شده‌اند را رمزگشایی می‌کند.

### چه زمانی نیاز دارید؟
اگر در قانون ارسال، **کلید رمزنگاری** تنظیم کرده باشید، هر پیام به صورت AES-256 رمزنگاری می‌شود. برنامه رمزگشا به شما اجازه می‌دهد متن اصلی را روی هر دستگاه اندرویدی بخوانید.

### نصب
فایل `SmsDecoder-x.x.x.apk` را از صفحه [Releases](https://github.com/toofanusir-svg/SmsHostForwarder/releases) دانلود کنید.

### نحوه استفاده

**روش اول — paste دستی:**
۱. برنامه SMS Decoder را باز کنید
۲. همان کلید رمزنگاری که در قانون ارسال تنظیم کردید را وارد کنید → **ذخیره**
۳. پیام رمزنگاری‌شده را در فیلد ورودی paste کنید
۴. **رمزگشایی** را بزنید → متن اصلی نمایش داده می‌شود
۵. **بستن** را بزنید تا نتیجه پنهان شود

**روش دوم — Share از برنامه دیگر:**
۱. در هر برنامه‌ای (چت، ایمیل، یادداشت) متن رمزنگاری‌شده را انتخاب کنید
۲. **Share** → **SMS Decoder** را انتخاب کنید
۳. برنامه با متن آماده باز می‌شود، **رمزگشایی** را بزنید

## پیش‌نیازها

- اندروید ۸.۰ (API 26) یا بالاتر
- گوشی قابلیت دریافت پیامک و تماس
- دسترسی به اینترنت
- توکن ربات تلگرام (رایگان، ۲ دقیقه طول می‌کشد)

## نصب

۱. به صفحه [Releases](https://github.com/toofanusir-svg/SmsHostForwarder/releases) بروید
۲. فایل `SmsForwarder-x.x.x.apk` را دانلود کنید
۳. فایل را روی گوشی باز کنید (اگر پرسید، «نصب از منبع ناشناخته» را اجازه دهید)
۴. برنامه را باز کنید

## نحوه کار

```
پیامک/تماس می‌رسد → برنامه همه قوانین فعال را چک می‌کند → هر قانون مطابق، مستقل و موازی اجرا می‌شود
                                                                              ↓
                                              ┌─────────────────────────────────┴─────────────────────────────────┐
                                              ↓                                                                   ↓
                                    ربات تلگرام (Telegram Bot API)                                          وب‌هوک سفارشی (Webhook URL)
```

همه قوانین مطابق **موازی** چک و اجرا می‌شوند — هیچ قانونی دیگری را مسدود نمی‌کند.

## ساخت ربات تلگرام

۱. تلگرام را باز کنید و **@BotFather** را جستجو کنید
۲. `/newbot` را بفرستید
۳. یک نام انتخاب کنید (مثلاً `My SMS Forwarder`)
۴. یک username با پسوند `bot` انتخاب کنید (مثلاً `my_sms_forwarder_bot`)
۵. BotFather یک **توکن HTTP API** می‌فرستد:
   ```
   7123456789:AAH-abcdefGHIjklmNOPqrstUVWxyz
   ```
۶. این توکن را کپی کنید — در برنامه استفاده خواهید کرد

## پیدا کردن شناسه چت

ربات تا زمانی که شما اول به آن پیام ندهید، نمی‌تواند به شما پیام بفرستد. به Chat ID عددی نیاز دارید:

۱. یک پیام (مثلاً `/start`) به ربات جدیدتان بفرستید
۲. این آدرس را در مرورگر باز کنید (به جای `TOKEN` توکن خود را بگذارید):
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
۳. در پاسخ `"chat":{"id":XXXXXXXXX}` را پیدا کنید — آن عدد شناسه چت شماست

> **نکته:** می‌توانید با کاما چند شناسه چت وارد کنید: `73638059,98765432`

## ساخت قانون

۱. برنامه را باز کنید — دکمه **+** را بزنید
۲. **نام قانون** — یک برچسب بدهید (مثلاً «پیامک بانک»)
۳. **سیم‌کارت** — هر سیم‌کارت، سیم‌کارت اول یا دوم
۴. **شماره فرستنده** — شماره خاص وارد کنید یا `*` برای همه
۵. **ربات تلگرام** — تیک بزنید و پر کنید:
   - **توکن ربات** — از BotFather
   - **شناسه چت‌ها** — با کاما جدا کنید
۶. **وب‌هوک** — اگر می‌خواهید، تیک بزنید و پر کنید:
   - **آدرس وب‌هوک** — آدرس سرور شما (باید با `https://` یا `http://` شروع شود)
   - **هدر Authorization** — اختیاری
۷. دکمه **Test** را بزنید تا قبل از ذخیره مطمئن شوید مقصد کار می‌کند
۸. **Save** را بزنید

### مثال قانون

| نام قانون | سیم‌کارت | فرستنده | تلگرام | وب‌هوک |
|-----------|---------|---------|--------|---------|
| همه پیامک‌ها | هر کدام | `*` | توکن + شناسه چت | — |
| هشدار بانک | هر کدام | `+9812345678` | توکن + شناسه چت | — |
| سیم ۱ → تلگرام | سیم ۱ | `*` | توکن + شناسه چت | — |
| سیم ۲ → سرور | سیم ۲ | `*` | — | `https://myserver.com/sms` |
| هر دو مقصد | هر کدام | `+9812345678` | توکن + شناسه چت | `https://myserver.com/sms` |

## تنظیم وب‌هوک

وقتی وب‌هوک تنظیم شود، برنامه یک HTTP POST به آدرس شما با این بدنه JSON می‌فرستد:

```json
{
  "message": "📱 *SIM 1* — From *+9812345678* at Wed Jan 15 14:30:00 GMT 2025\n\nYour verification code is `1234`"
}
```

یک سرور ساده برای دریافت (مثال Node.js / Express):

```javascript
const express = require('express');
const app = express();
app.use(express.json());

app.post('/sms', (req, res) => {
    console.log('Received:', req.body.message);
    res.json({ ok: true });
});

app.listen(3000, () => console.log('Webhook server running on :3000'));
```

اگر هدر Authorization تنظیم کنید (مثلاً `Bearer my-secret-token`)، برنامه آن را می‌فرستد:
```
Authorization: Bearer my-secret-token
```

## تست قوانین

### تست هر قانون (در صفحه ویرایش)
هنگام ساخت یا ویرایش قانون، دکمه **Test** را بزنید. با مقادیر فعلی فرم (بدون ذخیره) پیام تستی ارسال می‌کند و نتیجه ✅ یا ❌ نشان می‌دهد.

### تست کلی (صفحه اصلی)
دکمه **Test** در صفحه اصلی را بزنید. به همه قوانین فعال پیام تستی ارسال می‌کند و خلاصه نشان می‌دهد: چند موفق، چند ناموفق.

## لاگ ارسال

آیکون **Log** در نوار بالایی را بزنید تا تاریخچه ارسال را ببینید:

- ✅ سبز = ارسال موفق
- ❌ قرمز = ناموفق (با لمس، پیام خطا نشان داده می‌شود)
- ⏳ = در حال انجام

برای موارد ناموفق، دکمه **Retry** ظاهر می‌شود — بزنید تا دوباره تلاش کند.

لاگ ۵۰۰ مورد آخر را نگه می‌دارد. دکمه **Clear Log** تاریخچه را پاک می‌کند.

## تنظیمات

آیکون چرخ‌دنده در نوار بالایی:

- **زبان** — English یا فارسی
- **تم** — روشن یا تاریک

تغییرات بلافاصله اعمال می‌شوند. برنامه برای زبان جدید ری‌استارت می‌شود.

**پیش‌فرض:** انگلیسی، تم روشن.

## سرویس پس‌زمینه

- دکمه **Start** در صفحه اصلی را بزنید تا سرویس شروع شود
- سرویس به صورت **foreground service** با یک نوتیفیکیشن دائمی اجرا می‌شود (الزام اندروید)
- سرویس **sticky** است — اندروید آن را ری‌استارت می‌کند
- بعد از **ریست دستگاه**، سرویس خودکار شروع می‌شود
- دکمه **Stop** برای توقف دستی

## مشکلات رایج

### پیامک‌ها ارسال نمی‌شوند
- مطمئن شوید سرویس روشن است (دکمه Start غیرفعال باشد)
- صفحه **Log** را بررسی کنید
- با دکمه Test توکن را چک کنید
- مطمئن شوید اول `/start` به ربات فرستاده‌اید

### هشدار «تشخیص چند سیم‌کارت پشتیبانی نمی‌شود»
دستگاه شما از تشخیص چند سیم‌کارت پشتیبانی نمی‌کند. از «هر سیم‌کارت» استفاده کنید.

### برنامه کرش می‌کند
صفحه کرش با stack trace نشان داده می‌شود. **Copy** را بزنید و برای دیباگ بفرستید.

### وب‌هوک کار نمی‌کند
- مطمئن شوید آدرس با `https://` یا `http://` شروع شود
- در Log کد خطای HTTP را بررسی کنید
- با دکمه Test در صفحه ویرایش تست کنید

## امنیت

- برنامه از **توکن شخصی ربات تلگرام شما** استفاده می‌کند — داده‌ها مستقیم به سرورهای تلگرام می‌روند
- هیچ داده‌ای به سرور شخص ثالث ارسال نمی‌شود (جز وب‌هوک تنظیم‌شده توسط شما)
- داده‌های قانون (توکن‌ها، آدرس‌ها) در حافظه خصوصی برنامه ذخیره می‌شوند
- `allowBackup="false"` — داده‌ها در بکاپ سیستم نیستند
- اعتبارسنجی گواهینامه SSL/TLS فعال است
